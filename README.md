<h1>Kafka-Project-Producer-Consumer</h1>

<p>
This project is a simple implementation of a <b>Producer-Consumer system using Apache Kafka</b> for learning purposes.
</p>

<hr/>

<h2>📌 Description</h2>
<p>
In this project:
</p>
<ul>
  <li><b>Producer (Delivery Boy API)</b> generates random numeric data.</li>
  <li><b>Consumer (User API)</b> receives and displays that data in real time.</li>
</ul>

<p>
It demonstrates how data flows between services using Kafka topics.
</p>

<hr/>

<h2>⚙️ How It Works</h2>
<ol>
  <li>Producer generates random numbers</li>
  <li>Producer sends data to a Kafka topic</li>
  <li>Consumer subscribes to the topic</li>
  <li>Consumer reads and displays the data</li>
</ol>
